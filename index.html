About Me

I'm Mahendar Shivarathri, a Cloud & DevOps Engineer from Hyderabad with hands-on experience in Azure, AWS, CI/CD automation, Dockerization, and cloud-native application delivery.

With over 3.1+ years of experience, I specialize in building secure, scalable DevOps pipelines, automating deployments, optimizing cloud environments, and streamlining development workflows.

Currently working as an Azure DevOps Engineer at Mazik Tech Solutions Pvt Ltd I manage the complete product lifecycle in Azure DevOps, automate CRM processes, build CI/CD pipelines for .NET apps, and improve cloud security & infrastructure efficiency. I have also integrated SonarQube, developed monitoring dashboards, and built custom Docker images for optimized deployments.

Previously, I worked at Applied AI Consulting as a Junior Cloud Engineer where I migrated GitLab projects to GitHub, automated cloud infrastructure using Terraform, deployed workloads in Azure & AWS, and worked on Kubernetes, Docker, WordPress hosting, and SFTP automation.

I am well-versed in tools like Terraform, Jenkins, AKS, Kubernetes, Ansible, GitHub Actions, GitLab, Azure DevOps, and AWS services. I enjoy solving real-world DevOps challenges by reducing manual effort, improving deployment speed, and ensuring secure, reliable infrastructure.
