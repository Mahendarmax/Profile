About Me

I'm Mahendar Shivarathri — a Cyber Security & Cloud DevOps Engineer from Hyderabad, passionate about securing cloud environments and automating infrastructure at scale.

With over 3.6+ years of experience, I currently work as a Cyber Security Engineer at Bristol Myers Squibb (BMS), where I leverage tools like Wiz, ServiceNow, Python, and AI Automation to strengthen security posture and drive intelligent threat response.

Previously, as an Azure DevOps Engineer at Mazik Tech Solutions, I managed the complete product lifecycle in Azure DevOps, automated CRM processes, built CI/CD pipelines for .NET apps, integrated SonarQube for code quality, and created custom Docker images for optimized deployments.

I began my journey at Applied AI Consulting as a Junior Cloud Engineer, migrating GitLab projects to GitHub, automating infrastructure using Terraform, deploying workloads in Azure & AWS, and working on Kubernetes, Docker, and SFTP automation.

I'm well-versed in Terraform, Jenkins, AKS, Kubernetes, Ansible, GitHub Actions, GitLab, Azure DevOps, AWS services, Wiz, and ServiceNow. I enjoy solving real-world security and DevOps challenges — reducing risk, improving deployment speed, and ensuring resilient infrastructure.
